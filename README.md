# Motion (by VisionAce)

**Motion** is a real-time hearing and speaking assistive web application designed to help deaf and hard-of-hearing individuals follow speech, music, and ambient sounds through intuitive visual feedback during everyday interactions and public gatherings.

---

## 🚀 Features
- **Real-Time Sound Visual Feedback:** Converts audio nuances and speech into clear visual visual cues.
- **Offline-First Resilience:** Built with local storage capabilities to maintain usability in low-connectivity settings.
- **Accessible & Inclusive UI:** Designed with high contrast, readable typography, and responsive controls aligned with SDG 3 (Good Health & Well-being).

---

## 🛠️ Tech Stack
- **Frontend:** React, TypeScript, Vite, Tailwind CSS
- **Mobile Integration:** Capacitor
- **Backend / Database:** Supabase
